# Sources

All five documents in this folder were written by me for this project, with help from
an AI assistant. They describe a fictional organization's incident response program.
They are not copied from any published document.

| File | Source |
|------|--------|
| 01_ir_overview.md | Written by me. The four-phase lifecycle follows NIST SP 800-61 (Computer Security Incident Handling Guide), paraphrased, not quoted. |
| 02_severity_levels.md | Written by me. The severity levels and response times are invented for this fictional organization. |
| 03_phishing_playbook.md | Written by me, drawing on general industry practice for phishing triage (SPF/DKIM/DMARC checks, message purge, credential reset). |
| 04_ransomware_playbook.md | Written by me, drawing on general guidance such as the CISA #StopRansomware Guide, paraphrased, not quoted. |
| 05_evidence_handling.md | Written by me. The order of volatility follows RFC 3227 (Guidelines for Evidence Collection and Archiving), paraphrased. |

All policies, contact addresses, and numbers (response times, retention periods) are
fictional and do not describe any real organization.
